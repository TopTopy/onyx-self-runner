# ONYX Self Runner

Clean, secret-free self-bot runner designed to be deployed **one instance per account** on Railway (or any host).

This repository contains **zero hardcoded secrets**.  
All configuration is done via environment variables.

## How it works

1. Main management bot handles registration, payment and session creation.
2. After approval, the main bot uses Railway API to create a new service from this repo.
3. It injects the following environment variables and deploys:

| Variable            | Required | Description                                      |
|---------------------|----------|--------------------------------------------------|
| `API_ID`            | Yes      | Telegram API ID                                  |
| `API_HASH`          | Yes      | Telegram API Hash                                |
| `SESSION_STRING`    | Yes      | Telethon StringSession                           |
| `ACCOUNT_TOKEN`     | Yes      | Unique token generated by main bot for this user |
| `CONTROL_USER_IDS`  | No       | Comma-separated user IDs allowed to send commands|
| `MAIN_BOT_USERNAME` | No       | Username of the management bot                   |
| `PORT`              | No       | HTTP port (default 8080)                         |

## Local run

```bash
pip install -r requirements.txt
export API_ID=...
export API_HASH=...
export SESSION_STRING=...
export ACCOUNT_TOKEN=your-secret-token
python main.py
```

## Railway

Just connect this repo and set the environment variables.  
The service will start automatically.

## Control Protocol

The runner accepts commands from the main bot in two ways:

1. **Telegram** (recommended): Private messages from allowed control users containing a signed command.
2. **HTTP** (optional): `POST /command` with header `X-Account-Token: <ACCOUNT_TOKEN>`.
